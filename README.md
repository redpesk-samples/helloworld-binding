# Helloworld Binding

Helloworld Binding is a minimal AFB Binding V4 sample that showcases the basic mechanisms used to develop a binding in a redpesk context.

Checkout the documentation from the [`docs`](docs/) folder or on [the redpesk documentation](https://docs.redpesk.bzh/docs/en/master/redpesk-core/helloworld/1-Overview.html).
